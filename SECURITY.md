# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue.

Include what you found, how to reproduce it and the affected version. Malikan Inc. aims to acknowledge reports within five business days.

## Supported versions

Before v1.0.0, only the latest release receives security fixes.

## Scope

AssureKit generates synthetic data and runs tests. It must never contain real personal or financial data. If you find any, report it as a security issue.
